================================================================================
 3-WAY DECODE / INFERENCE BENCHMARK  —  raw metrics
 Model held constant across the three configs, run once per size.
================================================================================

Hardware   : NVIDIA GeForce RTX 4060 Laptop GPU (8 GB), laptop
Sources    : 7 local 1080p H.264 .mp4 clips (traffic / people / dogs)
             cars1 @25   cars2 @30   cars3 @30   dogs1 @30
             people1 @60 people2 @30 people3 @60
Model      : YOLO11n and YOLO11m, FP16 (A/B run the .pt with half=True;
             C runs the exported engine)
Recording  : every run composites the 7-tile mosaic and H.264-encodes it
             (a fixed cost carried by all three)
Metric     : "sustained FPS" = model invocations per second at steady state
             (median of the per-second aggregate). This is a rate, so it does
             not depend on run length.

Configurations:
  A  ocv.py  —  OpenCV VideoCapture (CPU / FFmpeg decode)  +  YOLO11n/m (PyTorch)   
  B  old.py  —  hardware-accelerated decode                +  YOLO11n/m (PyTorch)   
  C  new.py  —  hardware-accelerated decode                +  optimized engine

================================================================================
 NOTES
================================================================================
 * Same model (both sizes) is used for all three configs.
 * C is a real-time pipeline: it runs at its steady rate and does not block its
   decoders, so its FPS reflects sustained analysis throughput.
 * Detection counts vary between the FFmpeg path (A) and the hardware path
   (B, C) because the two hand the model slightly different pixels (YUV colour
   range). Not a throughput signal, so not tabulated.
 * Every figure includes compositing and encoding the 7-tile mosaic each run.
